# Changelog

## 0.4.0 — 2026-11-17

- Replace separate text fields with one continuous title-and-body editor.
- Drag across any text blocks and press Backspace/Delete to remove the selection.
- Normal copy/cut/paste and undo/redo across the page, with existing notes and
  block formatting preserved on load.
- Retain the collapsible sidebar, local saving and conversation panel.

## 0.3.0 — 2026-11-17

- Select all page writing with ⌘A/Ctrl+A or the Select all button, then clear it
  with Backspace/Delete. Includes the title; preserves the page and other notes.
- Undo the last whole-page clear/replacement before further edits or closing.
- Collapse or expand the page sidebar at every width; remember the preference.

## 0.2.0 — 2026-11-17

- Open Notes from the conversation's top toolbar into a tab beside chat.
- Remove the separate dock shortcut while retaining the original page address.
- Preserve the existing notebook and adapt its height to the panel.

## 0.1.0 — 2026-11-17

- Initial Notes notebook: pages, search, text blocks, headings, lists, checkboxes
  and quotes, with local autosave.
- Recoverable Trash, Markdown copy, manual backup and additive restore.
- GitHub installation from `dist` and automatic Buzz update checks.
